# Progressive Model Fidelity for Hail Impact — Paper 1 Reproducibility Release

Version: **v1.0.0**

This archive contains the frozen processed datasets, selected computational modules/drivers, evidence-domain tables, validation artifacts, and final figures supporting the manuscript:

**Determining the Minimum Modeling Fidelity Required for Engineering Impact Prediction: A Progressive Framework Demonstrated Using Hail Impact**

## Purpose

The study evaluates progressive modeling fidelity rather than assuming that the most complex model is always the most useful. The five conceptual levels are:

1. Model 1 — Baseline Translational Representation
2. Model 2 — Aerodynamic Fidelity
3. Model 3 — Environmental Fidelity
4. Model 4 — Reduced-Order Rigid-Body Fidelity
5. Model 5 — Euler Rigid-Body Fidelity

The release preserves explicit evidence boundaries. Model 5 is not forced through aerodynamic states lacking characterized lift/moment data, and peak contact forces are not reported beyond the adopted Sun et al. analytical application domain.

## Directory map

- `src/` — core computational modules/reference implementations available from the final development workflow.

## Important reproducibility note

This archive is a **curated publication release**, not a dump of the exploratory development directory. Preliminary contact-duration solvers, obsolete impulse calculations, failed/truncated Euler trajectories, superseded four-model scripts, and other exploratory artifacts were intentionally excluded.

Some final results were frozen as CSV outputs after iterative model-development and evidence-audit steps. The included scripts are the cleanest available computational modules and audit drivers from that workflow; they should not be interpreted as a single monolithic script that regenerates every archived CSV with one command. The frozen CSVs are the canonical numerical record for the manuscript release.

## Evidence terminology

Evidence status is component-specific. In particular, aerodynamic evidence status and contact-model evidence status are separate classifications and should not be conflated.

Typical labels include:

- directly characterized / directly calibrated
- interpolated
- published analytical application
- extrapolative / beyond published application range
- unsupported

## Model 5 boundary

The Euler rigid-body formulation requires orientation-dependent lift and aerodynamic-moment information over `(Re, theta, chi)`. The archived evidence-domain files document where the available List/Kry-derived coefficient information overlaps the nominal trajectory. Unsupported portions were retained as evidence boundaries rather than filled solely to complete a trajectory.

## Contact model boundary

Peak normal contact force is based on the deterministic maximum-contact-force formulation of Sun et al. The release does not claim a complete roofing-assembly structural model, post-peak fragmentation model, impulse model, or validated hailstone–asphalt-shingle friction law.
