**Title:** Progressive Model Fidelity for Hail Impact — Paper 1 Reproducibility Release

**Version:** 1.0.0

**Creator:** Christine Dailey Walck

**Description:**
Reproducibility release supporting the manuscript "Determining the Minimum Modeling Fidelity Required for Engineering Impact Prediction: A Progressive Framework Demonstrated Using Hail Impact." The archive contains curated computational modules, frozen production datasets, sensitivity analyses, evidence-domain classifications, validation artifacts, and figures for a five-level progressive hail-impact modeling framework. The release explicitly preserves aerodynamic and contact-model evidence boundaries and excludes superseded exploratory calculations.

**Suggested keywords:** hail impact; impact mechanics; model fidelity; rigid-body dynamics; aerodynamics; contact mechanics; engineering simulation; reproducibility; evidence-aware modeling
